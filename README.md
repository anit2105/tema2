# Instagram Clone

## Descripción del proyecto
Red social para compartir fotos y videos.

## Metodología
Se utilizará la metodología Agile Scrum.

## Ciclo de vida del proyecto

Planificación: Definir el objetivo y crear el backlog del producto.

Sprint: Trabajar en las tareas del backlog durante un período de tiempo.

Revisión: Revisar el trabajo realizado y obtener feedback.

Retrospectiva: Analizar el sprint y mejorar el proceso.

Roles

Product Owner (PO): Define y prioriza el backlog.

Scrum Master (SM): Facilita el proceso Scrum.

Desarrolladores: Trabajan en las tareas del backlog.

Reuniones

Planificación: Definir el objetivo del sprint.

Diaria: Revisar el progreso y planificar el día.

Revisión: Revisar el trabajo realizado.

Retrospectiva: Analizar el sprint y mejorar el proceso.

Productos

Backlog del producto: Lista de tareas del proyecto.

Incremento del producto: Producto entregado al final de cada sprint.

## Requisitos funcionales.
* Los usuarios deben poder crear una cuenta y iniciar sesión
* Los usuarios deben poder publicar fotos y videos
* Los usuarios deben poder comentar y dar likes a las publicaciones
* Los usuarios deben poder seguir a otros usuarios
* Los usuarios deben poder ver las publicaciones de los usuarios que siguen

## Requisitos no funcionales.
* La aplicación debe ser segura y proteger los datos de los usuarios
* La aplicación debe ser rápida y escalable
* La aplicación debe tener una interfaz intuitiva y fácil de usar

## Herramientas necesarias
* IDE: Visual Studio Code
* Lenguaje de programación: JavaScript (Node.js y React)
* Base de datos: MongoDB
* Herramienta de documentación: JSDoc
* Herramienta de pruebas: Jest
* Control de versiones: Git

  
## Resumen del proyecto Instagram Clone
El proyecto se llevará a cabo en 5 sprints de 2 semanas cada uno, utilizando la metodología Agile Scrum. A continuación, se describe de forma resumida cómo se llevará a cabo el proyecto:

Sprint 1: Autenticación de usuarios (Semanas 1-2)
Implementar la autenticación de usuarios
Crear API para registrar y autenticar a los usuarios

Sprint 2: Publicación de contenido (Semanas 3-4)
Implementar la publicación de fotos y videos
Crear API para subir y mostrar contenido

Sprint 3: Interacción con publicaciones (Semanas 5-6)
Implementar el sistema de comentarios y likes
Crear API para interactuar con las publicaciones

Sprint 4: Seguimiento de usuarios (Semanas 7-8)
Implementar el sistema de seguimiento de usuarios
Crear API para seguir y dejar de seguir a otros usuarios

Sprint 5: Página de inicio y despliegue (Semanas 9-10)

Implementar la página de inicio

Desplegar el proyecto en un entorno de producción
